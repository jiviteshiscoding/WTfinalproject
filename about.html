About the Project

The Survey Commission website is an educational Web Technologies mini project created to model a public survey and feedback collection portal.

Project Overview

This application simulates an online government survey commission where citizens can register demographic and professional details, submit constructive feedback, and administrative officers can access role-based login interfaces.

Project Objectives

  • Build a structured, multi-page static website with uniform navigation across all pages.
  • Implement diverse HTML5 form elements including text, date, radio buttons, checkboxes, dropdowns, and textareas.
  • Maintain clean and responsive visual styling using native CSS flexbox and media queries.
  • Provide client-side form validation and demo feedback using lightweight Vanilla JavaScript.
  • Ensure the website is fully functional when opened locally in standard web browsers.

Technologies Used

  • HTML5 Page layout, tables, semantic markup, and comprehensive form fields.
  • CSS3 Color styling, flexbox navigation bar, button hover effects, and responsive layout.
  • Vanilla JavaScript Client-side validation and interactive feedback handling without external libraries.

Main Website Modules

  • Home Module (index.html): Portal landing page with introduction, banner image, and links.
  • Why This Website? (why.html): Contextual page discussing the importance of online surveys and web technologies.
  • About Module (about.html): Documentation of project objectives, tech stack, and module structure.
  • Survey Registration Module (survey.html): Multi-field registration form for citizen data collection.
  • Feedback Module (feedback.html): Public opinion and grievance submission form.
  • Login Portal (login.html): Authentication gateway for Administrators and Survey Officers.

Student Mini-Project Context

This project was developed for a second-year engineering Web Technologies laboratory practical submission. It emphasizes readable code, adherence to basic web standards, and avoidance of complex frameworks or unnecessary dependencies.
